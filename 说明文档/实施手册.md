# 考级数据看板 - 实施手册 v4.0

---

## 一、每期操作只需关注这个文件夹

```
每期点击的程序\
├── 1_启动本期定时任务.bat   ← 报名开始【前】点一次（每期只点这一次）
├── 2_手动刷新看板.bat       ← 想立刻用现有数据刷新看板时点（验证用）
├── 3_停止定时任务.bat       ← 需要手动停止定时任务时点（一般不用）
└── 4_本期收尾留档.bat       ← 报名结束次日手动补跑用（定时任务会自动做）
```

---

## 二、每期完整操作流程

### 第一步：填写配置（每期做一次）

**1）打开 `数据源/本期考级目标.xlsx`，修改：**

| 字段 | 说明 | 2026Q4 示例 |
|------|------|------|
| 季度 | 本期季度标识 | 2026Q4 |
| 目标人数 | 本期目标报名人数 | 3673 |
| 目标课时 | 本期目标课时 | 13027 |
| 报名时间 | 用于看板展示 | 11.20-11.29 |
| 考试时间 | 用于看板展示 | 1.9-1.10 |
| **报名开始日期** | BI下载起始日期 + 定时任务起始日期（程序读取），格式 YYYY-MM-DD | 2026-11-20 |
| **报名结束日期** | BI下载截止日期 + 定时任务截止日期（程序读取），格式 YYYY-MM-DD | 2026-11-29 |
| **每日播报时间** | 每天几点自动更新，逗号分隔 | 10:30,14:00,18:00,23:59 |

**2）打开 `数据源/目标明细.xlsx` → `MTD` sheet，更新每日流速（D列总和必须精确=1.0）。**

> **注意**：`auto_download_bi.py` 与定时任务的日期均**自动从上面的 Excel 读取**，无需改代码。

---

### 第二步：验证配置（可选）

双击 `每期点击的程序/2_手动刷新看板.bat`，用现有数据重新生成看板，
在本地打开 `dashboard.html` 确认：季度标识、目标人数、MTD天数与流速正确。

---

### 第三步：启动定时任务（报名开始前 1 天）

双击 `每期点击的程序/1_启动本期定时任务.bat`

脚本自动完成：
- 读取 Excel 中的报名日期与播报时间
- 创建每日定时任务（**带起始日与截止日，报名区间外不会运行**）
- 创建「收尾归档任务」（报名结束次日 10:00 自动执行）

```
2026Q4 创建的任务示例：
  考级数据看板自动更新-1030   每天 10:30（2026/11/20 起，2026/11/29 止）
  考级数据看板自动更新-1400   每天 14:00（同上）
  考级数据看板自动更新-1800   每天 18:00（同上）
  考级数据看板自动更新-2359   每天 23:59（同上）
  考级数据收尾归档            2026-11-30 10:00（一次性）
```

---

### 第四步：报名期间（全自动，无需操作）

定时任务按配置时间自动执行：

```
定时触发 → auto_update_and_publish.py
   [1] 下载BI数据（使用Excel中的日期范围）
   [2] 生成看板 dashboard.html
   [3] 推送到 GitHub → Pages 自动更新（约1-2分钟）
```

监控方式：访问看板，查看左上角最后更新时间。

---

### 第五步：报名结束次日（自动收尾，通常无需操作）

`考级数据收尾归档` 任务在报名结束次日 10:00 **自动执行**：
1. 最后一次完整更新（下载BI + 生成看板 + 推送GitHub）
2. 自动归档本期数据到 `数据源/历史归档/`
3. 自动更新 `数据源/往期数据.xlsx`

**如需手动触发**，双击 `每期点击的程序/4_本期收尾留档.bat`。

---

### 下一期准备

收尾完成后，下期启动前只需：
1. 更新 `数据源/本期考级目标.xlsx`（改季度、日期、目标、播报时间）
2. 更新 `数据源/目标明细.xlsx` 的 `MTD` sheet（改流速）
3. 双击 `每期点击的程序/1_启动本期定时任务.bat`

**不需要**修改任何 Python 代码文件。

## 四、配置项速查

只需编辑 `数据源/本期考级目标.xlsx`：

| 字段 | 作用 |
|------|------|
| 报名开始日期 | BI下载起始日 + 定时任务起始日，格式 YYYY-MM-DD |
| 报名结束日期 | BI下载截止日 + 定时任务截止日，格式 YYYY-MM-DD |

## 五、常见问题

**Q：定时任务会在报名开始前一天误跑吗？**
A：不会。任务带 `/SD 报名开始日` 与 `/ED 报名结束日`，只在报名区间内运行，到期自动停止。

**Q：定时任务过了报名截止日还在跑？**
A：任务带 `/ED 结束日期`，到期自动停止。若有残留，双击 `3_停止定时任务.bat` 一键清除。

**Q：想修改播报时间怎么办？**
A：改 `本期考级目标.xlsx` 的「每日播报时间」，再双击 `1_启动本期定时任务.bat`（会删旧建新）。

**Q：MTD累计目标不对？**
A：检查 `目标明细.xlsx` 的 `MTD` sheet D列（每日流速），总和必须精确=1.0。

**Q：看板数据不更新？**
A：双击 `2_手动刷新看板.bat` 手动触发，查看错误提示。

**Q：归档文件在哪里？**
A：`数据源/历史归档/`，文件名形如 `2026Q4_考级统计归档.xlsx`。

**Q：看板密码在哪里改？**
A：`generate_dashboard.py` 第 25 行 `PASSWORD = "2026Q4"`。
