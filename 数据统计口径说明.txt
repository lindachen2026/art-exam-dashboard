考级数据看板 - 数据统计口径说明
========================================
生成时间：2026年11月
适用范围：美术考级数据可视化看板
本次密码：2026Q4
本期报名时间：2026-11-20 ~ 2026-11-29
本期考试时间：2027-01-09 ~ 2027-01-10

一、基础指标
----------------------------------------

1. 报名人数
   口径：考级学员信息表中，按用户ID去重后的报名人数
   数据源：考级学员信息表.xlsx → 用户id（去重计数）

2. 目标人数
   口径：本期考级人数目标
   数据源：本期考级目标.xlsx → 目标人数

3. 报名完成率
   口径：报名人数 / 目标人数 × 100%
   公式：total_reg_count / total_target

4. 课时达成
   口径：所有报名学员对应科目级别的标准课时之和
   数据源：考级学员信息表 × 考级各科目级别课时标准.xlsx
   匹配逻辑：按"科目名称+等级"匹配对应课时数

5. 课时目标
   口径：本期课时预扣目标
   数据源：本期考级目标.xlsx → 目标课时

6. 课时完成率
   口径：课时达成 / 课时目标 × 100%

7. 报名率（报考率）
   口径：池内已报名人数 / 池内总人数 × 100%
   分子：跟进学员名单中，学员ID出现在考级学员信息表中的人数
   分母：跟进学员名单总人数
   注意：此处是"池内"口径，不含池外报名学员

8. GMV（预估报名净收益）【已下线，不再呈现】
   口径：所有报名学员的"考级资格消耗"字段之和
   数据源：考级学员信息表.xlsx → 考级资格消耗（求和）

二、学区统计
----------------------------------------

1. 学区归属判定
   口径：通过跟进学员名单中的"学区"字段判定
   已知学区：教学一区、教学二区、教学三区、C区、DEMO特战队
   学区维度的报名人数：该学区池内学员中已报名的人数

2. 无归属
   口径：考级学员信息表中所有报名学员 - 已归属到5个学区的报名学员
   即：报名了但无法通过跟进学员名单归到任何已知学区的学员
   包含：池外学员 + 池内但学区字段不在5个已知学区中的学员
   地区拆分：按考级学员信息表中的"学员地区"字段判定（中国大陆/中国港澳台/海外）

3. 学区完成率
   口径：学区实际报名人数 / 学区目标人数 × 100%
   数据源：目标明细.xlsx → 团队 sheet（学区目标行）

4. 学区报名率
   口径：学区内已报名人数 / 学区池内总人数 × 100%

三、首报/复报判定
----------------------------------------

1. 复报
   口径：跟进学员名单中"累计报考次数" >= 1 且本期有报名的学员
   即：之前考过级，本次又报名了

2. 首报
   口径：以下两类学员之和
   a) 池内学员：跟进学员名单中"累计报考次数"为空或为0，且本期有报名
   b) 池外学员：在考级学员信息表中有报名记录，但不在跟进学员名单中的学员
      （池外学员全部视为首报）

3. 首报占比
   口径：首报人数 / (首报人数 + 复报人数) × 100%

四、中国大陆 / 中国港澳台 / 海外
----------------------------------------

1. 池内口径
   判定字段：跟进学员名单 → "地区"列
   中国大陆 = 地区字段为"国内"
   中国港澳台 = 地区字段为"港澳台"
   海外 = 地区字段为"国内"、"港澳台"以外的其余值
   说明：往期数据中仅有"国内/海外"两分类，中国港澳台为2026Q4新增细分，
        无历史对照，其"上期报考率"在看板中留空。

2. 报名表口径（用于无归属和整体统计）
   判定字段：考级学员信息表 → "学员地区"列

3. 中国大陆/中国港澳台/海外报名率
   口径：对应地区池内已报名 / 对应地区池内总人数

五、科目统计
----------------------------------------

1. 科目报名人数
   口径：按"考试科目名称"分组，对用户ID去重计数
   注意：同一学员报多个科目会分别计入各科目

2. 科目课时
   口径：该科目所有报名记录的标准课时之和

3. 科目首报/复报拆分
   口径：将每个报名记录的学员标记为首报或复报（同三），再按科目分组统计

4. 科目级别报名排名
   口径：按"科目名称+等级"组合分组统计报名人数，降序排列
   对比：与往期数据中"科目级别上期报名数据"sheet的上期数据对比

5. 科目级别构成
   本期上线级别：儿童画1-5级、素描2-10级、漫画3-10级、国画花鸟3-6级、速写1-5级
   说明：2026Q4新增国画花鸟6级、速写5级；国画花鸟1级、2级本期不再开设
   （科目级别不硬编码，全部由"考级学员信息表 × 考级各科目级别课时标准"动态生成）

六、学员分层
----------------------------------------

1. 分层字段
   数据源：跟进学员名单 → "分层"列
   分类：A层、B层、C层、D层、E层
   说明：E层为2026Q4新增分层，往期数据中无对应记录

2. 各层报考率
   口径：该分层池内已报名人数 / 该分层池内总人数

3. 环比
   口径：本期报考率 - 上期报考率（百分点差值）
   数据源：往期数据.xlsx → 学员分层的往期对比 sheet
   说明：E层因无往期数据，环比留空（看板显示"—"），不做跨期对比

七、阶段分布
----------------------------------------

1. 阶段字段
   数据源：跟进学员名单 → "阶段"列
   分类：L1、L2、L3、L4、L5、L6、高阶、院派、大师、不在班
   未匹配到以上阶段的学员归入"不在班"

2. 各阶段报名率
   口径：该阶段池内已报名 / 该阶段池内总人数

八、满级学员
----------------------------------------

1. 满级判定
   口径：跟进学员名单中"推荐漫画报考级别"或"推荐素描报考级别"字段值为"已满级"
   满足任一条件即判定为满级学员

2. 满级报名率
   口径：满级学员中已报名 / 满级学员总数

九、每日报名趋势（MTD）
----------------------------------------

1. 每日报名人数
   口径：按报名时间的日期分组，对用户ID去重计数

2. 累计报名
   口径：从报名首日起，逐日累加当日新增报名人数

3. MTD目标
   口径：每日流速目标逐日累加
   数据源：目标明细.xlsx → MTD sheet

十、团队页面
----------------------------------------

1. 团队/小组完成率
   口径：该团队(小组)实际报名人数 / 该团队(小组)目标人数
   数据源：目标明细.xlsx → 团队 sheet

2. 老师TOP3
   口径：按老师维度统计报名人数，取前3名
   匹配：通过学员ID将报名记录关联到跟进学员名单中的"老师艺名"

3. 荣誉榜 - 个人TOP10
   排序依据：加权后的报名人数（从高到低）
   表格列：排名、艺名、目标学员数、报名人数、完成率、首报人数、加权后的报名人数、学区

   各列口径：
   a) 目标学员数：目标明细.xlsx → "老师" sheet → "目标学员数 向上取整"
   b) 报名人数：该老师跟进学员中本期已报名人数（考级学员信息表匹配跟进学员名单）
   c) 完成率：报名人数 / 目标学员数 × 100%
   d) 首报人数：该老师名下本期报名学员中，跟进学员名单"累计报考次数"为空或0的人数
   e) 加权后的报名人数：首报人数 × 1.5 + 复报人数 × 1.0
      （首报权重1.5，复报权重1.0，鼓励拓新）
   f) 学区：老师所属学区

3. 学区 vs 大盘对比
   口径：各项指标的学区值 与 全局值 进行并列对比
   大盘 = 跟进学员名单全量数据计算的各项比率

十一、往期对比
----------------------------------------

1. 环比
   口径：本期值 与 上一个季度值的对比
   人数环比 = (本期 - 上期) / 上期 × 100%
   报考率环比 = 本期报考率 - 上期报考率（百分点差值）

2. 同比
   口径：本期值 与 去年同季度值的对比
   计算方式同环比

3. 季度周期
   每年3个考级周期：Q1（约3月）、Q3（约7月）、Q4（约10月）

十二、数据源文件说明
----------------------------------------

| 文件名 | 用途 |
|--------|------|
| 考级学员信息表.xlsx | 本期所有报名记录 |
| 目标明细.xlsx | 团队/老师目标、跟进学员池、MTD目标 |
| 考级各科目级别课时标准.xlsx | 科目级别对应的标准课时 |
| 往期数据.xlsx | 历史各期对比数据 |
| 本期考级目标.xlsx | 本期整体目标和季度标识 |
